# 碳排放核算系统 - 用户操作手册

## 一、系统概述

本系统是一个用于碳排放核算的管理平台，旨在帮助用户管理和追踪各类能耗设备（电力表、天然气表等）的基础数据。系统提供了参数配置、数据字典管理等核心功能，为碳排放计算和报告提供数据支撑。

### 主要功能模块

| 模块          | 说明                  |
| ----------- | ------------------- |
| 碳排放核算参数设置   | 统一管理各类参数配置的入口       |
| 碳排放因子设置     | 管理电力、化石燃料、热力等排放因子数据 |
| 能耗数据自动采集点设置 | 管理电力表、天然气表等采集设备     |
| 碳排放模型数据字典设置 | 管理系统中使用的各类数据字典      |

## 三、碳排放因子设置

### 3.1 功能说明

本模块用于管理各类碳排放因子数据，这些数据是进行碳排放核算的基础参数。

### 3.2 外购电力排放因子设置

#### 功能说明

管理外购电力的排放因子数据，用于计算电力消耗产生的碳排放。

#### 字段说明

| 字段   | 说明            | 单位       |
| ---- | ------------- | -------- |
| 年份   | 排放因子所属年份      | -        |
| 地区   | 适用地区（如华东、华北等） | -        |
| 排放因子 | 该地区的电力排放因子    | tCO₂/MWh |
| 数据来源 | 排放因子的参考来源     | -        |
| 更新时间 | 数据最后更新时间      | -        |

#### 操作说明

- **新增**：点击"新增电力排放因子"按钮，在弹出的对话框中填写相关信息并保存。
- **编辑**：在列表中找到目标记录，点击右侧的"编辑"按钮进行修改。
- **删除**：点击右侧的"删除"按钮，确认后删除该记录。

### 3.3 化石燃料排放因子设置

#### 功能说明

管理各类化石燃料（如煤、天然气、柴油等）的排放因子数据。

#### 字段说明

| 字段      | 说明                 | 单位     |
| ------- | ------------------ | ------ |
| 燃料类型    | 燃料的种类（如烟煤、天然气、柴油等） | -      |
| 排放因子    | 该燃料的排放因子           | tCO₂/吨 |
| 低位发热量   | 燃料的低位发热量           | kJ/kg  |
| 单位热值含碳量 | 燃料的单位热值含碳量         | tC/GJ  |
| 氧化率     | 燃料燃烧的氧化率           | %      |

#### 操作说明

- **新增**：点击"新增化石燃料排放因子"按钮进行添加。
- **编辑/删除**：通过列表右侧的操作按钮进行修改或删除。

### 3.4 外购热力排放因子设置

与外购电力排放因子设置操作类似，用于管理热力排放因子。

### 3.5 废弃物排放因子设置

#### 固体废弃物焚烧排放因子

管理固体废弃物焚烧处理过程中的排放因子。

#### 废水处理排放因子

管理废水处理过程中的排放因子。

## 四、能耗数据自动采集点设置

### 4.1 电力表设置

#### 功能说明

本模块用于管理电力采集设备的层级结构，支持"站点/区间 → 集中器 → 电表"的三级组织结构。用户可以对各层级节点进行新增、编辑、删除、移动等操作。

#### 页面结构

页面采用左右分栏布局：

- **左侧**：树状结构展示，显示完整的层级关系
- **右侧**：详情面板，展示选中节点的详细信息

#### 节点层级关系

```
根节点
├── 站点/区间（第一级）
│   ├── 集中器（第二级）
│   │   ├── 电表（第三级）
│   │   └── 电表（可级联，形成父子关系）
│   └── ...
└── ...
```

#### 4.1.1 树节点操作

##### 展开/折叠树

- **展开全部**：点击根节点上的"展开全部"按钮，展开所有层级
- **折叠全部**：点击根节点上的"折叠全部"按钮，只显示根节点
- **展开/折叠单个节点**：点击节点左侧的箭头图标

##### 添加站点/区间

1. 点击根节点上的"+"按钮
2. 在弹出的对话框中填写站点信息：
   - **名称**：必填，站点或区间的名称
   - **拼音编码**：系统根据名称自动生成，无需手动填写
   - **描述**：可选，填写站点的说明信息
3. 点击"确定"保存

##### 添加集中器

1. 点击目标站点节点上的"+"按钮
2. 在弹出的对话框中填写集中器信息：
   - **名称**：必填，集中器的名称
   - **拼音编码**：系统自动生成
   - **变压器容量**：可选，填写变压器的容量参数
   - **集中器地址**：必填，远程抄表的地址编码（仅支持数字）
   - **描述**：可选
3. 点击"确定"保存

##### 添加电表

1. 点击目标集中器或电表节点上的"+"按钮
2. 在弹出的对话框中填写电表信息：
   - **名称**：必填，电表的名称
   - **拼音编码**：系统自动生成
   - **电表类型**：从下拉框选择（支持数据字典配置）
   - **电表型号**：点击输入框右侧的"+"图标，在弹窗中选择已有的电表型号
   - **电表地址**：必填，远程抄表的地址编码（仅支持数字）
   - **抄表方式**：选择"自动抄表"或"人工抄表"
   - **用电分类**：选择用电类型（生产用电、生产辅助用电、混合）
   - **能耗数据划拨**：选择划拨方式（肃分、原分、机辆、其他）
   - **描述**：可选
3. 点击"确定"保存

##### 编辑节点

1. 在左侧树中点击选中要编辑的节点
2. 右侧详情面板将显示该节点的详细信息
3. 点击详情面板上的"编辑"按钮
4. 在对话框中修改相关信息
5. 点击"确定"保存

##### 移动节点（上移/下移）

1. 将鼠标悬停在要移动的节点上
2. 点击出现的上移箭头或下移箭头按钮
3. 节点将在同级节点中进行位置交换

**注意**：

- 只能在同级节点中移动
- 第一个节点无法上移，最后一个节点无法下移

##### 启用/停用节点

1. 将鼠标悬停在目标节点上
2. 点击"停用"或"启用"按钮
3. 系统将切换该节点的状态

**说明**：

- 停用后的节点在树中显示为灰色，并带有"停用"标签
- 处于停用状态的节点下的设备不会参与数据采集

##### 删除节点

1. 将鼠标悬停在目标节点上
2. 点击删除按钮（红色垃圾桶图标）
3. 在确认对话框中点击"确定"完成删除

**重要提示**：

- 删除会同时删除该节点及其所有子节点
- 只能删除已停用的节点，启用状态的节点无法删除
- 删除操作不可恢复，请谨慎操作

#### 4.1.2 更改电表级联关系

当多个电表需要建立主从关系时，可通过此功能设置电表的级联关系。

1. 在树中点击选中一个电表节点
2. 在右侧详情面板底部点击"更改电表级联关系"按钮
3. 在弹出的对话框中：
   - **当前电表**：显示正在操作的电表名称
   - **选择上级电表**：
     - 选择"无上级电表"表示该电表为顶级电表
     - 选择列表中的其他电表作为其上级电表
4. 点击"确认"保存

**说明**：

- 只能选择同一集中器下的其他电表作为上级
- 级联关系影响数据采集的层级结构

#### 4.1.3 更改电表从属数据集中器

当电表需要从一个集中器迁移到另一个集中器时使用此功能。

1. 在树中点击选中一个电表节点
2. 在右侧详情面板底部点击"更改电表从属数据集中器"按钮
3. 在弹出的对话框中：
   - **选择从属数据集中器**：从列表中选择新的集中器
   - **选择上级电表**：选择在新集中器下的上级电表（可选）
4. 点击"确认"保存

**说明**：

- 只能选择同一站点下的集中器
- 切换集中器后，上级电表默认重置为"无上级电表"

#### 4.1.4 电表型号管理

在添加或编辑电表时，需要选择电表型号。点击电表型号输入框的"+"图标，将打开电表型号选择弹窗。

##### 选择已有型号

1. 在弹窗的搜索框中输入关键词进行筛选：
   - 输入英文字母：按拼音首字母筛选
   - 输入中文：按型号名称模糊搜索
2. 从列表中选择一个型号（支持单选或双击快速选择）
3. 点击"选择"按钮确认

##### 新增电表型号

1. 在电表型号选择弹窗中点击"新增"按钮
2. 在弹出的对话框中填写：
   - **电表型号**：必填，型号的名称
   - **所属类型**：从下拉框选择（单相、三相三线、三相四线）
   - **描述**：可选
3. 点击"保存"

##### 编辑电表型号

1. 在电表型号列表中找到目标型号
2. 点击右侧的"修改"按钮
3. 修改相关信息后点击"保存"

##### 删除电表型号

1. 在电表型号列表中找到目标型号
2. 点击右侧的"删除"按钮
3. 在确认对话框中点击"确认删除"

### 4.2 天然气表设置

本模块的操作方式与电力表设置类似，用于管理天然气采集设备的层级结构。

## 五、碳排放模型数据字典设置

### 5.1 功能说明

本模块用于管理系统中使用的各类数据字典。数据字典为系统中的下拉框选项、枚举值等提供统一的数据来源，确保数据的规范性和一致性。

### 5.2 页面结构

页面分为上下两个区域：

- **上部**：字典分类选择区域
- **下部**：字典项列表区域

### 5.3 字典分类管理

#### 5.3.1 选择字典分类

在"字典分类选择"下拉框中选择已有的字典分类。下拉框显示格式为：字典名称 + 字典编码 + 描述。

选择后，下方列表将自动加载该分类下的所有字典项。

#### 5.3.2 新增字典分类

1. 点击下拉框右侧的"新增"按钮
2. 在弹出的对话框中填写：
   - **字典编码**：必填，只能包含字母、数字和下划线，且以字母或下划线开头（如 `meter_type`）
   - **字典名称**：必填，字典的中文名称
   - **描述**：可选，字典的说明信息
   - **排序号**：0-999，用于控制显示顺序
3. 点击"确定"保存

**注意**：

- 字典编码创建后不可修改
- 编码规则：`^[a-zA-Z_][a-zA-Z0-9_]*$`

#### 5.3.3 编辑字典分类

1. 从下拉框中选择要编辑的字典分类
2. 点击"编辑"按钮
3. 修改字典名称、描述或排序号
4. 点击"确定"保存

#### 5.3.4 删除字典分类

1. 从下拉框中选择要删除的字典分类
2. 点击"删除"按钮
3. 系统会自动检查该分类下是否有启用的字典项：
   - **如果有启用的字典项**：系统将弹出提示，要求先禁用或删除所有启用的字典项后才能删除分类
   - **如果没有启用的字典项**：系统将弹出确认对话框，确认后删除该分类及其所有字典项

**重要**：删除字典分类会同时删除其下所有字典项，请谨慎操作。

### 5.4 字典项管理

选择一个字典分类后，下方表格将显示该分类下的所有字典项。

#### 表格字段说明

| 列名    | 说明                 |
| ----- | ------------------ |
| 字典项编码 | 字典项的唯一标识编码         |
| 字典项值  | 字典项的显示值或实际值        |
| 父级编码  | 父级字典项的编码（用于建立层级关系） |
| 状态    | 显示字典项是否启用（启用/禁用）   |

#### 5.4.1 新增字典项

1. 点击字典项列表右上角的"新增"按钮
2. 在弹出的对话框中填写：
   - **字典项编码**：必填，字典项的编码
   - **字典项值**：必填，字典项的值
   - **父级编码**：可选，从下拉框中选择父级字典项（用于层级字典）
   - **排序号**：0-999，用于控制显示顺序
3. 点击"确定"保存

#### 5.4.2 编辑字典项

1. 在表格中找到要编辑的字典项
2. 点击操作列的"编辑"图标
3. 修改相关信息
4. 点击"确定"保存

#### 5.4.3 删除字典项

1. 在表格中找到要删除的字典项
2. 点击操作列的"删除"图标
3. 在确认对话框中点击"确定"完成删除

#### 5.4.4 调整排序（上移/下移）

1. 在表格中找到要调整顺序的字典项
2. 点击操作列的"上移"或"下移"图标
3. 系统将交换该项与相邻项的位置

**说明**：

- 第一项无法上移，最后一项无法下移
- 排序会同时更新后端数据

#### 5.4.5 启用/停用字典项

1. 在表格中找到目标字典项
2. 点击操作列的启用/停用图标按钮
3. 系统切换该字典项的状态

**状态说明**：

- **启用**（绿色标签）：该字典项在系统中可用
- **禁用**（灰色标签）：该字典项在系统中不可用

**提示**：已被其他模块引用的字典项建议先停用，确认无影响后再删除。

## 六、常见问题与解答

### Q1：树状结构中无法添加新节点怎么办？

**检查清单**：

1. 确认当前节点是否允许添加子节点：
   - 站点节点可以添加集中器
   - 集中器节点可以添加电表
   - 电表节点可以添加子电表（建立级联关系）
2. 如果按钮不可用，可能是节点类型限制

### Q2：删除节点时提示"该节点处于启用状态"？

系统规则：只能删除已停用的节点。请先停用该节点，然后再执行删除操作。

### Q3：电表型号选择弹窗中搜索不到型号？

**可能的原因**：

1. 型号名称与搜索关键词不匹配
2. 使用拼音首字母搜索时，需输入型号名称的拼音首字母（如搜索"单相"可输入"DX"）
3. 如果确实没有该型号，请点击"新增"按钮创建

### Q4：更改电表级联关系时提示"该集中器下暂无其他电表"？

这表示当前电表所在的集中器下没有其他电表可作为其上级。此时只能选择"无上级电表"或先添加其他电表。

### Q5：删除字典分类时提示有启用的字典项？

系统规则：含有启用字典项的分类无法删除。请先将所有字典项停用（点击状态切换按钮），然后再尝试删除分类。

### Q6：集中器地址或电表地址输入不了字母？

这是系统的安全校验机制。集中器地址和电表地址仅支持数字（0-9），输入的字母会被自动过滤掉。

### Q7：拼音编码是如何生成的？

系统会根据节点名称自动生成拼音编码。例如输入"三汲站信号楼"，系统会自动生成对应的拼音首字母编码。该编码在创建后不可修改。

## 八、数据依赖关系说明

### 8.1 模块间依赖

```
数据字典设置（基础数据）
    ↓ 提供字典选项
电力表设置 / 天然气表设置
    ↓ 产生采集数据
碳排放核算
```

### 8.2 建议操作顺序

1. **首次使用系统时**：
   
   - 先在"数据字典设置"中配置所需的字典项
   - 然后在"电力表设置"和"天然气表设置"中管理设备
   - 最后在"碳排放因子设置"中维护排放因子数据

2. **新增设备前**：
   
   - 确认所需的电表型号、电表类型等字典是否已配置
   - 如需新增字典，请先在"数据字典设置"中添加
