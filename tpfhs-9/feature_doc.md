# 碳排放模型设计系统 - 功能描述文档

## 1. 系统概述

碳排放模型设计系统是一个基于浏览器访问的Web应用，用于帮助用户创建、管理和配置碳排放核算模版。系统采用前后端分离架构，前端使用Vue 3 + Element Plus，后端使用Spring Boot + JPA + MySQL。

## 2. 功能模块

| 会话管理 | 登录成功后将用户信息存储在本地存储中 | ✅ 已实现 |
| 用户退出 | 清除本地存储并返回登录页面      | ✅ 已实现 |

**登录流程：**

## 4. 核心业务流程

### 4.1 登录流程

```
用户访问 → 登录页面 → 输入用户名密码 → 后端验证 → 存储用户信息 → 跳转模版列表
```

### 4.2 模版创建与编辑流程

```
新建模版 → 输入名称和描述 → 保存 → 创建成功 → 打开模版编辑
            ↓
打开已有模版 → 编辑树形结构 → 添加/删除/修改节点 → 保存属性 → 更新模版
```

### 4.3 节点操作流程

```
选中节点 → 查看属性 → 点击修改 → 编辑属性 → 点击保存/取消
            ↓
点击+号 → 选择节点类型 → 输入配置 → 保存 → 更新树形结构
            ↓
点击-号 → 确认删除 → 删除节点及子节点 → 更新树形结构
```

### 4.4 计划任务执行流程

```
设置计划任务 → 配置执行周期和时间 → 保存配置 → 定时任务调度器检测 → 执行核算
```

## 7. 定时任务

### 7.1 调度器

- **类名**: `EmissionScheduler`
- **调度频率**: 每分钟检查一次
- **功能**: 根据模版的计划任务配置，在指定时间自动执行碳排放核算

### 7.2 核算服务

- **接口**: `EmissionCalculationService`
- **方法**: `executeEmissionCalculation(Long templateId)`
- **状态**: 空函数实现，等待具体核算逻辑
