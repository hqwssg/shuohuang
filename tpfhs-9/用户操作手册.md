# 碳排放核算系统 - 用户操作手册

## 一、系统概述

本系统是一个用于碳排放核算的管理平台，旨在帮助用户管理和追踪各类能耗设备（电力表、天然气表等）的基础数据。系统提供了参数配置、数据字典管理等核心功能，为碳排放计算和报告提供数据支撑。

### 主要功能模块

| 模块          | 说明                                |
| ----------- | --------------------------------- |
| 碳排放核算参数设置   | 统一管理各类参数配置的入口（排放因子、采集点、数据字典、参数设置） |
| 碳排放因子设置     | 管理电力、化石燃料、热力等排放因子数据               |
| 能耗数据自动采集点设置 | 管理电力表、天然气表等采集设备                   |
| 碳排放模型数据字典设置 | 管理系统中使用的各类数据字典                    |
| 参数设置        | 能耗三级分类字典的管理（生产用能/生产辅助用能/综合用能三级分类） |
| 碳排放模型设计     | 构建碳排放核算模版树，配置核算子节点与排放数据采集点（详见第七章） |

---

## 三、碳排放因子设置

### 3.1 功能说明

本模块用于管理各类碳排放因子数据，这些数据是进行碳排放核算的基础参数。

### 3.2 外购电力排放因子设置

#### 功能说明

管理外购电力的排放因子数据，用于计算电力消耗产生的碳排放。

#### 字段说明

| 字段   | 说明            | 单位       |
| ---- | ------------- | -------- |
| 年份   | 排放因子所属年份      | -        |
| 地区   | 适用地区（如华东、华北等） | -        |
| 排放因子 | 该地区的电力排放因子    | tCO₂/MWh |
| 数据来源 | 排放因子的参考来源     | -        |
| 更新时间 | 数据最后更新时间      | -        |

#### 操作说明

- **新增**：点击"新增电力排放因子"按钮，在弹出的对话框中填写相关信息并保存。
- **编辑**：在列表中找到目标记录，点击右侧的"编辑"按钮进行修改。
- **删除**：点击右侧的"删除"按钮，确认后删除该记录。

### 3.3 化石燃料排放因子设置

#### 功能说明

管理各类化石燃料（如煤、天然气、柴油等）的排放因子数据。

#### 字段说明

| 字段      | 说明                 | 单位     |
| ------- | ------------------ | ------ |
| 燃料类型    | 燃料的种类（如烟煤、天然气、柴油等） | -      |
| 排放因子    | 该燃料的排放因子           | tCO₂/吨 |
| 低位发热量   | 燃料的低位发热量           | kJ/kg  |
| 单位热值含碳量 | 燃料的单位热值含碳量         | tC/GJ  |
| 氧化率     | 燃料燃烧的氧化率           | %      |

#### 操作说明

- **新增**：点击"新增化石燃料排放因子"按钮进行添加。
- **编辑/删除**：通过列表右侧的操作按钮进行修改或删除。

### 3.4 外购热力排放因子设置

与外购电力排放因子设置操作类似，用于管理热力排放因子。

### 3.5 废弃物排放因子设置

#### 固体废弃物焚烧排放因子

管理固体废弃物焚烧处理过程中的排放因子。

#### 废水处理排放因子

管理废水处理过程中的排放因子。

## 四、能耗数据自动采集点设置

### 4.1 电力表设置

#### 功能说明

本模块用于管理电力采集设备的层级结构，支持"站点/区间 → 集中器 → 电表"的三级组织结构。用户可以对各层级节点进行新增、编辑、删除、移动等操作。

#### 页面结构

页面采用左右分栏布局：

- **左侧**：树状结构展示，显示完整的层级关系
- **右侧**：详情面板，展示选中节点的详细信息

#### 节点层级关系

```
根节点
├── 站点/区间（第一级）
│   ├── 集中器（第二级）
│   │   ├── 电表（第三级）
│   │   └── 电表（可级联，形成父子关系）
│   └── ...
└── ...
```

#### 4.1.1 树节点操作

##### 展开/折叠树

- **展开全部**：点击根节点上的"展开全部"按钮，展开所有层级
- **折叠全部**：点击根节点上的"折叠全部"按钮，只显示根节点
- **展开/折叠单个节点**：点击节点左侧的箭头图标

##### 添加站点/区间

1. 点击根节点上的"+"按钮
2. 在弹出的对话框中填写站点信息：
   - **名称**：必填，站点或区间的名称
   - **拼音编码**：系统根据名称自动生成，无需手动填写
   - **描述**：可选，填写站点的说明信息
3. 点击"确定"保存

##### 添加集中器

1. 点击目标站点节点上的"+"按钮
2. 在弹出的对话框中填写集中器信息：
   - **名称**：必填，集中器的名称
   - **拼音编码**：系统自动生成
   - **变压器容量**：可选，填写变压器的容量参数
   - **集中器地址**：必填，远程抄表的地址编码（仅支持数字）
   - **描述**：可选
3. 点击"确定"保存

##### 添加电表

1. 点击目标集中器或电表节点上的"+"按钮

2. 在弹出的对话框中填写电表信息：
   
   - **名称**：必填，电表的名称
   - **拼音编码**：系统自动生成
   - **电表类型**：从下拉框选择（支持数据字典配置）
   - **电表型号**：点击输入框右侧的"+"图标，在弹窗中选择已有的电表型号
   - **电表地址**：必填，远程抄表的地址编码（仅支持数字）
   - **抄表方式**：选择"自动抄表"或"人工抄表"
   - **能耗场景大类**：从下拉框选择一级能耗分类（如生产用能、生产辅助用能、非生产综合用能、混合场景用能，数据来源于能耗分类字典）
   - **能耗二级分类**：选择"能耗场景大类"后自动加载其下属二级分类供选择
   - **能耗三级分类**：选择"能耗二级分类"后自动加载其下属三级分类供选择
   - **能耗数据划拨**：选择划拨方式（肃分、原分、机辆、其他）
   - **总表与分表关系**：选择总表与下属分表的汇总关系（"总表计数等于各下属分表计数之和"或"不等于"）。当选择"不等于"时，可在该电表下创建虚拟电表用于分摊核算（见 4.1.5）
   - **是否累加量**：选择是否为累加计量（1=是，0=否）
   - **是否移动源**：选择是否为移动排放源（1=是，0=否）
   - **计量单位**：选择或填写计量单位（如 MWh、吨、m³）
   - **数据来源系统**：选择数据来源系统
   - **能耗用途分类**：填写能耗用途分类说明
   - **计费周期单位/周期起始日期/周期长度**：非累加量场景下用于配置计费周期（周/月/季度/年）
   - **用途描述**：可选
   
   > **说明**：原"用电分类"字段已从表单移除，改由"能耗场景大类/二级/三级分类"三级级联下拉框替代；新建电表时，能耗场景分类默认取 EC03/EC0303/EC030303（非生产综合用能→生产辅助附属→福利区）。

3. 点击"确定"保存

> **添加下级电表类型选择**：当父电表的"总表与分表关系"设置为"不等于"（即总表计数不等于各下属分表计数之和）时，点击其"+"按钮，系统会先检查该电表下是否已存在虚拟电表；若无虚拟电表，将弹出选择框，由您选择"添加下级实体电表"或"添加下级虚拟电表"。选择"虚拟电表"创建的节点将以橙色背景+斜体+[虚]标签样式显示（详见 4.1.5）。

##### 编辑节点

1. 在左侧树中点击选中要编辑的节点
2. 右侧详情面板将显示该节点的详细信息
3. 点击详情面板上的"编辑"按钮
4. 在对话框中修改相关信息
5. 点击"确定"保存

##### 移动节点（上移/下移）

1. 将鼠标悬停在要移动的节点上
2. 点击出现的上移箭头或下移箭头按钮
3. 节点将在同级节点中进行位置交换

**注意**：

- 只能在同级节点中移动
- 第一个节点无法上移，最后一个节点无法下移

##### 启用/停用节点

1. 将鼠标悬停在目标节点上
2. 点击"停用"或"启用"按钮
3. 系统将切换该节点的状态

**说明**：

- 停用后的节点在树中显示为灰色，并带有"停用"标签
- 处于停用状态的节点下的设备不会参与数据采集

##### 删除节点

1. 将鼠标悬停在目标节点上
2. 点击删除按钮（红色垃圾桶图标）
3. 在确认对话框中点击"确定"完成删除

**重要提示**：

- 删除会同时删除该节点及其所有子节点
- 只能删除已停用的节点，启用状态的节点无法删除
- 删除操作不可恢复，请谨慎操作

#### 4.1.2 更改电表级联关系

当多个电表需要建立主从关系时，可通过此功能设置电表的级联关系。

1. 在树中点击选中一个电表节点
2. 在右侧详情面板底部点击"更改电表级联关系"按钮
3. 在弹出的对话框中：
   - **当前电表**：显示正在操作的电表名称
   - **选择上级电表**：
     - 选择"无上级电表"表示该电表为顶级电表
     - 选择列表中的其他电表作为其上级电表
4. 点击"确认"保存

**说明**：

- 只能选择同一集中器下的其他电表作为上级
- 级联关系影响数据采集的层级结构

> **限制**：当选中的电表为"虚拟电表"（is_virtual_meter=1）或"虚拟分摊子电表"（is_allocation_child=1）时，"更改电表级联关系"按钮会隐藏，即这两类节点不能修改级联关系。实体电表不受此限制。详见 4.1.5。

#### 4.1.3 更改电表从属数据集中器

当电表需要从一个集中器迁移到另一个集中器时使用此功能。

1. 在树中点击选中一个电表节点
2. 在右侧详情面板底部点击"更改电表从属数据集中器"按钮
3. 在弹出的对话框中：
   - **选择从属数据集中器**：从列表中选择新的集中器
   - **选择上级电表**：选择在新集中器下的上级电表（可选）
4. 点击"确认"保存

**说明**：

- 只能选择同一站点下的集中器
- 切换集中器后，上级电表默认重置为"无上级电表"

> **限制**：当选中的电表为"虚拟电表"（is_virtual_meter=1）或"虚拟分摊子电表"（is_allocation_child=1）时，"更改电表从属数据集中器"按钮会隐藏，即这两类节点不能更改从属集中器。实体电表不受此限制。详见 4.1.5。

#### 4.1.5 虚拟电表与虚拟分摊子电表

为支持总表-分表汇总关系"不等于"（即总表计数不等于各下属分表计数之和）场景下的能耗分摊核算，系统提供"虚拟电表"与"虚拟分摊子电表"两类特殊节点。

##### 概念说明

###### 虚拟电表

虚拟电表主要用于解决总表-子表架构下的计量盲区问题。
当总表下挂载若干子表，但存在部分负载直接由总表供电且未安装物理子表时，创建虚拟电表。该表计不依赖物理传感器，而是通过“总表读数 - 所有子表读数之和”的差值算法，自动计算并统计这部分未计量的用电数据，确保能耗统计的完整性。

场景描述：在总-分表计量拓扑中，存在部分直连总表的负载未配置物理计量设备。
处理逻辑：系统引入虚拟电表（Virtual Meter）概念。
计算公式：虚拟电表读数 = 总表当前读数 - Σ(所有关联物理子表当前读数)
目的：将未计量的线损或直连负载纳入数字化管理，实现能耗数据的100%覆盖。

###### 虚拟分摊子电表

虚拟分摊子电表主要用于解决多部门共用单一物理电表的能耗核算问题。
当多个部门（或组织机构）共用一块电表时，为满足精细化的成本统计需求，系统支持创建虚拟分摊子电表。通过配置分摊规则，系统可将总表电量按比例自动拆分并映射至各虚拟子表，从而实现各部门用电量的独立核算与统计。

场景描述：存在多部门/组织机构共用同一物理电表的情况，需进行内部能耗结算。
处理逻辑：引入虚拟分摊子电表作为逻辑计量节点。
功能实现：基于预设的分摊比例或规则，将物理主表的电量数据动态拆分并写入对应的虚拟子表中。
目的：实现共用能耗的精细化归属与独立核算。

| 节点类型    | 标识字段                  | 树节点样式         | 用途                                           |
| ------- | --------------------- | ------------- | -------------------------------------------- |
| 实体电表    | is_virtual_meter=0    | 默认样式          | 真实物理电表，参与实际数据采集                              |
| 虚拟电表    | is_virtual_meter=1    | 橙色背景+斜体+[虚]标签 | 用于分摊核算的逻辑电表，无对应物理设备                          |
| 虚拟分摊子电表 | is_allocation_child=1 | 蓝色背景+[分摊]标签   | 挂接在电表下的分摊子节点，按分摊比例（allocationRatio）参与父表的能耗分摊 |

##### 创建虚拟电表

1. 选中一个电表节点，将其"总表与分表关系"设置为"不等于"并保存
2. 点击该电表节点上的"+"（添加下属电表）按钮
3. 系统检测到其下尚无虚拟电表，弹出选择框：
   - 选择"添加下级实体电表"：创建普通实体子表（流程同 4.1.1 添加电表）
   - 选择"添加下级虚拟电表"：创建虚拟电表，创建后该节点以橙色背景+斜体+[虚]标签显示
4. 在弹出表单中填写电表信息并保存

> **说明**：同一父电表下只能存在一个虚拟电表；若已存在虚拟电表，再次点击"+"将直接创建实体子表，不再弹出选择框。

##### 创建/修改虚拟分摊子电表

虚拟分摊子电表用于按比例分摊父电表的能耗数据，支持一次批量创建与修改多个分摊子电表。

1. 将鼠标悬停在目标电表节点上

2. 点击出现的"⿾"（网格图标）按钮（标题为"创建/修改虚拟分摊子电表"）
   
   > **说明**：分摊子电表节点（is_allocation_child=1）上不显示该按钮，即分摊子电表不能再挂接分摊子电表。

3. 系统先检查该电表节点是否已包含下属虚拟分摊子电表，然后弹出"创建/修改虚拟分摊子电表"对话框：
   
   - **若无已有分摊子电表**：列表初始化为空，仅可新增
   - **若已有分摊子电表**：列表自动加载所有已有的分摊子电表（含电表名称与分摊比例），可直接修改

4. 在对话框中编辑分摊子电表列表：
   
   - 点击"新增"按钮添加一行（新增行无 ID 标记，确定时执行插入）
   - 点击行右侧"编辑"按钮修改该行名称与比例
   - 点击行右侧"删除"按钮移除该行：
     - 若移除的是**已有**分摊子电表（带 ID），确定时将执行**删除**操作
     - 若移除的是**新增**行（无 ID），仅从列表中移除，不产生数据库操作

5. 系统校验列表中所有剩余行的分摊比例之和必须**等于 1**，否则提示错误并阻止提交（已删除的行不参与求和）

6. 点击"确定"保存，系统按以下规则分别处理：
   
   | 操作类型       | 触发条件                 | 执行动作                                                          |
   | ---------- | -------------------- | ------------------------------------------------------------- |
   | 更新（update） | 列表中保留的已有分摊子电表（带 ID）  | 调用 PUT 接口更新名称与分摊比例                                            |
   | 新增（insert） | 列表中新增的分摊子电表（无 ID）    | 调用 POST 接口插入，`is_allocation_child=1`，`is_virtual_meter` 继承父节点 |
   | 删除（delete） | 从列表中移除的已有分摊子电表（带 ID） | 若原状态为启用先停用，再调用 DELETE 接口删除                                    |
   
   > **说明**：删除已有分摊子电表时，系统会先将其停用（后端要求删除前节点必须为停用状态），再执行删除。分摊子电表为末端节点，无下级子表，停用操作不受级联约束影响。

7. 保存成功后提示"成功更新X个、新增Y个、删除Z个虚拟分摊子电表"，并自动刷新树结构。创建/修改后的分摊子电表以蓝色背景+[分摊]标签显示。

##### 修改分摊比例

分摊比例的修改统一通过"创建/修改虚拟分摊子电表"对话框完成，确保父节点下属所有分摊子电表的比例之和为 1。

1. 在左侧树中点击选中一个"虚拟分摊子电表"节点
2. 点击右侧详情面板的"编辑"按钮，打开编辑表单
3. 编辑表单中"分摊比例"字段为只读，右侧有"修改分摊比例"按钮：
   - **非分摊子电表**（is_allocation_child=0）：按钮始终为**禁用**状态（灰色不可点）
   - **分摊子电表**（is_allocation_child=1）：按钮可点击
4. 点击"修改分摊比例"按钮，系统自动定位该分摊子电表的**父节点**，并弹出"创建/修改虚拟分摊子电表"对话框，列出父节点下属所有分摊子电表
5. 在对话框中统一修改各分摊子电表的比例（确保比例之和为 1），操作流程同上文"创建/修改虚拟分摊子电表"

##### 操作限制汇总

为确保分摊核算逻辑的完整性，虚拟电表与虚拟分摊子电表对部分操作做了限制：

| 节点类型    | "添加下属电表"按钮 | "创建/修改虚拟分摊子电表"按钮 | "更改电表级联关系"按钮 | "更改电表从属数据集中器"按钮 |
| ------- | ---------- | ---------------- | ------------ | --------------- |
| 实体电表    | 显示         | 显示               | 显示           | 显示              |
| 虚拟电表    | 隐藏         | 隐藏               | 隐藏           | 隐藏              |
| 虚拟分摊子电表 | 隐藏         | 隐藏               | 隐藏           | 隐藏              |

> **注**：实体电表不受上述限制，可正常进行所有操作。

#### 4.1.6 能耗场景三级分类

电表表单中的"能耗场景分类"采用三级级联下拉框，数据来源于系统的"能耗分类数据字典"（sys_emission_energy_category 表）。分类字典本身可通过"参数设置 → 能耗三级分类设置"页进行管理（新增/编辑/删除一级、二级、三级分类），详见第六章。

##### 分类层级

| 层级  | 字段         | 示例                                             |
| --- | ---------- | ---------------------------------------------- |
| 一级  | 能耗场景大类（L1） | 生产用能 EC01、生产辅助用能 EC02、非生产综合用能 EC03、混合场景用能 EC04 |
| 二级  | 能耗二级分类（L2） | 牵引供电 EC0101、办公区 EC0301 等                       |
| 三级  | 能耗三级分类（L3） | 接触网损耗 EC010101、福利区 EC030301 等                  |

##### 级联选择规则

1. 打开电表编辑表单时，"能耗场景大类"下拉框自动加载全部一级分类
2. 选中某一级分类后，"能耗二级分类"下拉框自动加载该一级下的二级分类
3. 选中某二级分类后，"能耗三级分类"下拉框自动加载该二级下的三级分类
4. **重置规则**：
   - 修改"能耗场景大类"时，已选的二级与三级分类自动清空
   - 修改"能耗二级分类"时，已选的三级分类自动清空
5. 新建电表时，三级分类默认取 EC03/EC0303/EC030303（非生产综合用能→生产辅助附属→福利区）

##### 分类原则

- 宜细不宜粗，条件允许时应细化至三级
- 监测点未覆盖细分项目时，可只选到第一级（大类）统计

### 4.2 化石燃料采集设置

#### 功能说明

本模块用于管理化石燃料能耗数据采集设备的层级结构，支持"采集范围 → 细分范围 → 采集点"的三级组织结构。采集点支持多级子表挂接（如总表下挂子表），适用于原煤、天然气、柴油等化石燃料的计量场景。

#### 页面结构

页面采用左右分栏布局：

- **左侧**：树状结构展示，显示完整的层级关系
- **右侧**：详情面板，展示选中节点的详细信息

#### 节点层级关系

```
根节点（化石燃料采集设置）
├── 采集范围（第一级，如"原平分公司"）
│   ├── 细分范围（第二级，如"炼焦车间"）
│   │   ├── 采集点（第三级，如"1号焦炉计量表"）
│   │   └── 采集点（可级联，形成父子关系）
│   └── ...
└── ...
```

#### 4.2.1 树节点操作

##### 展开/折叠树

- **展开全部**：点击根节点上的"展开全部"按钮，展开所有层级
- **折叠全部**：点击根节点上的"折叠全部"按钮，只显示根节点
- **展开/折叠单个节点**：点击节点左侧的箭头图标

> **说明**：新增、编辑、删除、上下移动、启停等操作后，树的展开状态会自动保持不变。

##### 添加采集范围

1. 点击根节点上的"+"按钮
2. 在弹出的对话框中填写：
   - **名称**：必填，采集范围的名称（如"原平分公司"）
   - **拼音编码**：系统根据名称自动生成，无需手动填写
   - **描述**：可选，填写说明信息
3. 点击"确定"保存

> **说明**：新增节点默认添加到同级末尾。

##### 添加细分范围

1. 点击目标采集范围节点上的"+"按钮
2. 在弹出的对话框中填写：
   - **名称**：必填，细分范围的名称（如"炼焦车间"）
   - **拼音编码**：系统自动生成
   - **描述**：可选
3. 点击"确定"保存

##### 添加采集点

1. 点击目标细分范围或采集点节点上的"+"按钮
2. 在弹出的对话框中填写采集点信息：
   - **名称**：必填，采集点的名称
   - **拼音编码**：系统自动生成
   - **燃料类型**：从下拉框选择（烟煤、天然气、柴油等，数据来源于数据字典）
   - **计量表型号**：手动输入计量表型号文本
   - **抄表方式**：选择"自动抄表"或"人工录入"
   - **能耗场景大类/二级分类/三级分类**：三级级联下拉框，数据来源于能耗分类数据字典（详见 4.1.6）。原"核算场景"字段已替换为该三级分类
   - **能耗用途**：填写能耗用途说明（该字段在表单中默认隐藏，需要时显示）
   - **能耗数据归属**：选择归属方式（肃分、原分、机辆、其他）
   - **用途描述**：可选
   - **自动抄表配置**：可选，JSON格式配置

> **说明**：新建采集点时，能耗场景分类默认取 EC03/EC0303/EC030303（非生产综合用能→生产辅助附属→福利区）。

> **说明**：
> 
> - "所属细分范围"和"上级采集点"字段在新增表单中**不显示**，系统会根据您点击的节点位置自动填充：
>   - 在细分范围节点下添加 → 所属细分范围 = 该细分范围，无上级采集点
>   - 在采集点节点下添加 → 所属细分范围 = 该采集点的细分范围，上级采集点 = 该采集点
> - 编辑模式下，"所属细分范围"和"上级采集点"以只读形式展示，如需修改请使用"更改采集点级联关系"和"更改采集点所属细分范围"功能。

3. 点击"确定"保存

##### 编辑节点

1. 在左侧树中点击选中要编辑的节点
2. 右侧详情面板将显示该节点的详细信息
3. 点击详情面板上的"编辑"按钮
4. 在对话框中修改相关信息
5. 点击"确定"保存

##### 移动节点（上移/下移）

1. 将鼠标悬停在要移动的节点上
2. 点击出现的上移箭头或下移箭头按钮
3. 节点将在同级节点中进行位置交换

**注意**：

- 只能在同级节点中移动
- 第一个节点无法上移，最后一个节点无法下移

##### 启用/停用节点

1. 将鼠标悬停在目标节点上
2. 点击"停用"或"启用"按钮
3. 系统将切换该节点的状态

**说明**：

- 停用后的节点在树中显示为灰色，并带有"停用"标签
- 处于停用状态的节点下的设备不会参与数据采集

##### 删除节点

1. 将鼠标悬停在目标节点上
2. 点击删除按钮（红色垃圾桶图标）
3. 在确认对话框中点击"确定"完成删除

**重要提示**：

- 删除会同时删除该节点及其所有子节点
- 只能删除已停用的节点，启用状态的节点无法删除
- 删除采集点时，其子采集点会自动解除父子关系（parent_meter_id 置为0）
- 删除操作不可恢复，请谨慎操作

#### 4.2.2 更改采集点级联关系

当多个采集点需要建立主从关系时，可通过此功能设置采集点的级联关系（即指定上级采集点）。

1. 在树中点击选中一个采集点节点
2. 在右侧详情面板底部点击"更改采集点级联关系"按钮
3. 在弹出的对话框中：
   - **当前采集点**：显示正在操作的采集点名称
   - **选择上级采集点**：
     - 选择"无上级采集点"表示该采集点为顶级采集点
     - 选择列表中的其他采集点作为其上级采集点
4. 点击"确认"保存

**说明**：

- 只能选择同一细分范围下的其他采集点作为上级
- 级联关系影响数据采集的层级结构
- 更改级联关系不会改变采集点的所属细分范围

#### 4.2.3 更改采集点所属细分范围

当采集点需要从一个细分范围迁移到另一个细分范围时使用此功能。

1. 在树中点击选中一个采集点节点

2. 在右侧详情面板底部点击"更改采集点所属细分范围"按钮

3. 在弹出的对话框中：
   
   - **当前采集点**：显示正在操作的采集点名称
   
   - **选择所属细分范围**：从列表中选择新的细分范围
     
     > 列表只显示当前采集点所属采集范围下的细分范围
   
   - **选择上级采集点**：选择在新细分范围下的上级采集点（可选）
     
     > 切换细分范围后，上级采集点列表会自动刷新，默认选中"无上级采集点"

4. 点击"确认"保存

**重要说明**：

- 只能选择同一采集范围下的细分范围
- **子节点同步更新**：如果当前采集点下有子采集点，更改所属细分范围后，所有子孙采集点的所属细分范围都会**自动同步更新**为新的细分范围
- 切换细分范围后，上级采集点默认重置为"无上级采集点"

### 4.3 天然气表设置

本模块的操作方式与电力表设置类似，用于管理天然气采集设备的层级结构。

## 五、碳排放模型数据字典设置

### 5.1 功能说明

本模块用于管理系统中使用的各类数据字典。数据字典为系统中的下拉框选项、枚举值等提供统一的数据来源，确保数据的规范性和一致性。

### 5.2 页面结构

页面分为上下两个区域：

- **上部**：字典分类选择区域
- **下部**：字典项列表区域

### 5.3 字典分类管理

#### 5.3.1 选择字典分类

在"字典分类选择"下拉框中选择已有的字典分类。下拉框显示格式为：字典名称 + 字典编码 + 描述。

选择后，下方列表将自动加载该分类下的所有字典项。

#### 5.3.2 新增字典分类

1. 点击下拉框右侧的"新增"按钮
2. 在弹出的对话框中填写：
   - **字典编码**：必填，只能包含字母、数字和下划线，且以字母或下划线开头（如 `meter_type`）
   - **字典名称**：必填，字典的中文名称
   - **描述**：可选，字典的说明信息
   - **排序号**：0-999，用于控制显示顺序
3. 点击"确定"保存

**注意**：

- 字典编码创建后不可修改
- 编码规则：`^[a-zA-Z_][a-zA-Z0-9_]*$`

#### 5.3.3 编辑字典分类

1. 从下拉框中选择要编辑的字典分类
2. 点击"编辑"按钮
3. 修改字典名称、描述或排序号
4. 点击"确定"保存

#### 5.3.4 删除字典分类

1. 从下拉框中选择要删除的字典分类
2. 点击"删除"按钮
3. 系统会自动检查该分类下是否有启用的字典项：
   - **如果有启用的字典项**：系统将弹出提示，要求先禁用或删除所有启用的字典项后才能删除分类
   - **如果没有启用的字典项**：系统将弹出确认对话框，确认后删除该分类及其所有字典项

**重要**：删除字典分类会同时删除其下所有字典项，请谨慎操作。

### 5.4 字典项管理

选择一个字典分类后，下方表格将显示该分类下的所有字典项。

#### 表格字段说明

| 列名    | 说明                 |
| ----- | ------------------ |
| 字典项编码 | 字典项的唯一标识编码         |
| 字典项值  | 字典项的显示值或实际值        |
| 父级编码  | 父级字典项的编码（用于建立层级关系） |
| 状态    | 显示字典项是否启用（启用/禁用）   |

#### 5.4.1 新增字典项

1. 点击字典项列表右上角的"新增"按钮
2. 在弹出的对话框中填写：
   - **字典项编码**：必填，字典项的编码
   - **字典项值**：必填，字典项的值
   - **父级编码**：可选，从下拉框中选择父级字典项（用于层级字典）
   - **排序号**：0-999，用于控制显示顺序
3. 点击"确定"保存

#### 5.4.2 编辑字典项

1. 在表格中找到要编辑的字典项
2. 点击操作列的"编辑"图标
3. 修改相关信息
4. 点击"确定"保存

#### 5.4.3 删除字典项

1. 在表格中找到要删除的字典项
2. 点击操作列的"删除"图标
3. 在确认对话框中点击"确定"完成删除

#### 5.4.4 调整排序（上移/下移）

1. 在表格中找到要调整顺序的字典项
2. 点击操作列的"上移"或"下移"图标
3. 系统将交换该项与相邻项的位置

**说明**：

- 第一项无法上移，最后一项无法下移
- 排序会同时更新后端数据

#### 5.4.5 启用/停用字典项

1. 在表格中找到目标字典项
2. 点击操作列的启用/停用图标按钮
3. 系统切换该字典项的状态

**状态说明**：

- **启用**（绿色标签）：该字典项在系统中可用
- **禁用**（灰色标签）：该字典项在系统中不可用

**提示**：已被其他模块引用的字典项建议先停用，确认无影响后再删除。

## 六、参数设置

本章节介绍"参数设置"一级菜单下属的功能模块。目前包含"能耗三级分类设置"，用于维护按能耗使用场景划分的三级分类字典（生产用能/生产辅助用能/综合用能等）。该字典数据会被"电力表设置""化石燃料采集设置"等模块的"能耗场景大类/二级分类/三级分类"级联下拉框引用。

### 6.1 能耗三级分类设置

#### 6.1.1 页面入口

#### 6.1.4 新增分类

**一级分类新增**：点击左列表头右上角的 **"新增一级分类"** 按钮。

**二级分类新增**：在左列选中目标一级分类行 → 点击中列表头右上角的 **"新增二级分类"** 按钮。

**三级分类新增**：在中列选中目标二级分类行 → 点击右列表头右上角的 **"新增三级分类"** 按钮。

| 字段   | 说明                                                                                                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 分类编码 | 必填，系统全局唯一。可手动输入，也可点击输入框右侧的 **"自动生成"** 按钮。自动生成规则：一级使用 `EC+两位序号`（如 EC05）；二级在父编码后追加两位序号（如 EC0101 表示 EC01 下的第 1 个二级）；三级在二级父编码后继续追加两位序号（如 EC010101）。若同级已存在相同序号，按钮会自动在末尾叠加拼音首字母后缀以避免冲突 |
| 分类名称 | 必填，中文显示名称（长度 ≤ 100）                                                                                                                                                              |
| 备注   | 可选，长度 ≤ 500 的补充说明                                                                                                                                                                |
| 排序号  | 可选，数值越小越靠前；留空时系统自动取同级当前最大值 + 1                                                                                                                                                   |
| 状态   | 启用（默认）/ 停用                                                                                                                                                                       |

点击 **"确定"** 保存。若分类编码已被占用或字段校验不通过，系统会提示具体错误。新增后对应列的列表自动刷新并按排序号顺序显示。

在任意层级的表格中，点击目标行"操作"列的 **"编辑"图标**（✎），系统弹出"编辑××分类"对话框，可修改：

- 分类编码（需与其它分类全局唯一，若已被引用建议谨慎修改）
- 分类名称
- 备注
- 排序号
- 状态（启用/停用）

分类所属的层级与父级关系在编辑对话框中 **不可修改**；如需调整上下级归属，请删除后在目标父级下重新新增。

#### 6.1.6 删除分类

在任意层级的表格中，点击目标行"操作"列的 **"删除"图标**（🗑），系统会：

1. 先查询该分类下属的子分类数量：
   - 删除一级分类时：提示"该分类下包含 N 个二级分类、N 个三级分类，删除后将**级联删除**其下属所有二级/三级分类"
   - 删除二级分类时：提示"该分类下包含 N 个三级分类，删除后将**级联删除**其下属所有三级分类"
   - 删除三级分类时：仅提示"确定删除该三级分类吗？"
2. 若该分类已被电力表/化石燃料采集点等模块引用，删除可能造成数据不一致，**请务必先在相应模块中更换为其它分类后再操作**
3. 点击 **"确定"** 后执行物理删除（数据库级联 ON DELETE CASCADE）

> **强烈建议**：删除前请先将分类状态切换为"停用"并在业务模块中替换引用，确认无误后再执行最终删除。

## 七、碳排放模型设计

### 7.1 功能说明

碳排放模型设计用于构建企业/项目的碳排放核算模版：以树状结构组织"核算子节点、排放数据采集点、运输生产碳排放核算节点"等节点，并为每个排放数据采集点关联具体的能耗数据采集设备（电力表/化石燃料采集点/外购热能采集点）。

系统区分两类模版：

- **核算模版**（templateType=2）：参与碳排放自动化核算，支持计划任务调度，可使用"挂载节点模版"功能将节点模版的子结构挂载到其核算点下；
- **节点模版**（templateType=1）：仅用于构建层级关系，作为结构被挂载引用，不参与碳排放自动化核算，模版属性弹窗中不显示"计划任务设置"面板。

### 7.2 页面入口与页面结构

- 登录系统后，从首页进入"碳排放核算模版管理"列表页，打开某个模版即进入设计页面；点击页面左上角圆形返回按钮可回到列表页。
- 页面分为三部分：
  - **左侧"树状结构展栏"**：展示模版节点树，鼠标悬停节点可进行添加、删除、上移/下移等操作；根节点(typeId=1)与核算子节点(typeId=2)悬停时还会显示"挂载节点模版"按钮，核算子节点额外显示"添加多个采集节点"按钮；
  - **右侧"属性显示栏"**：展示选中节点的属性详情；当选中根节点或核算子节点时，顶部"编辑"按钮左侧会额外显示"添加多个采集节点""挂载节点模版"两个按钮（功能与树结构中对应按钮完全一致），点击"编辑"按钮打开"编辑节点"弹窗；
  - **顶部标题栏**：显示当前模版名称，并提供"返回列表""新建模版""另存为"等入口。

### 7.3 节点类型

| 类型ID | 节点类型        | 说明                         |
| ---- | ----------- | -------------------------- |
| 1    | 根节点         | 模版树的根，"碳排放核算"              |
| 2    | 核算子节点       | 组织/区域级核算单元，可维护编码、边界说明等核算信息 |
| 3    | 排放数据采集点     | 关联一个具体采集设备，承载该设备的碳排放因子等配置  |
| 4    | 运输生产碳排放核算节点 | 运输生产相关核算节点，配置方式与核算子节点类似    |

### 7.4 添加"排放数据采集点"（单选）

1. 在目标父节点上点击"+"按钮，节点类型选择"排放数据采集点"；
2. 输入节点名称（可用"添加前缀"按钮自动补充名称前缀）；
3. 点击"选择采集点"按钮，打开**能耗数据采集点选择弹窗**：
   - 弹窗顶部选择排放数据大类：购入的电力（PE）/ 购入的热力（PH）/ 化石燃料（FF）；
   - 按"一级范围 → 二级范围 → 采集点"三列逐级选择一个采集点；
   - 双击采集点行（或选中后点击"确定"）完成选择；
4. 选择确认后，系统自动回填：排放数据大类、采集设备编号（自动生成）、采集点关联信息，并在弹窗下方以文字展示**已选采集点信息**（名称、能耗品种小类、所属能耗场景分类、计量单位、数据来源系统、计费周期等，均为只读，来源于该采集设备记录）；
5. 可继续设置碳排放因子（支持从因子库选择或手动输入，手动修改时描述会自动标注）、采集点描述；
6. 点击"确定"保存节点。

### 7.5 批量添加"排放数据采集点"（多选）

在**核算子节点**（typeId=2）上点击"添加多个采集节点"按钮，进入多选模式：

1. 选择排放数据大类后，在采集点列表中用复选框勾选多个采集点；
2. 在弹窗底部统一设置**碳排放因子设置、碳排放因子单位、碳排放因子描述**（必填）；
3. 点击"确定"后，系统为每个选中的采集点自动创建一个"排放数据采集点"子节点（节点名称取采集点名称，设备编号按规则逐个生成），并提示成功/失败数量。

**查重校验规则**（每个采集点在同一碳排放模版中只能存在一个）：

- 若所选采集点中有已存在于当前模版树中的，系统将提示"XXX、YYY采集点已经存在，不能添加！每个采集点在同一碳排放模版中只能存在一个。"；
- **全部重复**：弹窗保持打开，等待您调整选择；
- **部分重复**：弹窗关闭，仅创建未重复的采集点节点；
- 注意：新建节点后需等待树刷新完成，新创建的采集点节点才会被识别为"已存在"。

### 7.6 编辑节点（排放数据采集点）

选中"排放数据采集点"节点后，在右侧属性显示栏点击"编辑"打开编辑节点弹窗：

| 字段      | 说明                                                |
| ------- | ------------------------------------------------- |
| 节点名称    | 可修改                                               |
| 节点类型    | 只读展示，不可更改                                         |
| 能耗品种大类  | 下拉选择（购入的电力/购入的热力/化石燃料等），更改后小类清空并重新生成设备编号          |
| 采集设备编号  | 系统按父节点编码规则自动生成，只读                                 |
| 碳排放因子设置 | 支持从因子库选择或手动输入                                     |
| 碳排放因子单位 | 选择因子后自动带出，只读                                      |
| 碳排放因子描述 | 选择因子后自动带出，只读；手动修改因子时自动标注                          |
| 采集点描述   | 可自由填写                                             |
| 已选采集点信息 | 只读文字展示关联采集设备的名称、能耗品种小类、能耗场景分类、计量单位、数据来源系统、计费周期等信息 |

> **字段精简说明（v2.3）**：早期版本编辑节点弹窗中的以下字段已全部移除，不再展示、不再保存：统计口径类型、数据来源、核算场景、能耗用途、是否累计量、是否移动源、计量单位、数据来源系统、数据采集方式（获取方式）、分摊比例、是否有下级子表、核算误差约束、更新周期、更新时间、数据采集计划任务配置。
> 采集点的计量单位、数据来源系统、是否累计量等属性现统一由其关联的采集设备（在"能耗数据自动采集点设置"模块中维护）提供，并在"已选采集点信息"区域只读展示；如需调整这些属性，请前往对应的采集设备管理页面修改。
> 数据采集计划任务请在"模版管理"的模版属性中配置（模版级计划任务），不再支持按采集点单独配置。

### 7.7 其他节点操作

- **编辑核算子节点/运输生产碳排放核算节点**：可维护节点名称、节点编码、名称简称（用于自动生成子节点名称前缀）、是否纳入碳排放核算（取消勾选需二次确认）、节点类型、单位说明、组织边界说明、运营边界说明等；
- **上移/下移**：悬停节点后点击箭头按钮，在同级节点间调整顺序；
- **删除**：悬停节点后点击删除按钮并确认，删除会级联删除其所有子节点，不可恢复。

### 7.8 挂载节点模版

"挂载节点模版"用于将一个已建好的**节点模版**（templateType=1）所包含的全部子节点一次性复制到当前核算模版树的指定核算点之下，避免手工逐个重建层级结构。

**入口**（二选一）：

- 在左侧树状结构中，鼠标悬停**根节点(typeId=1)**或**核算子节点(typeId=2)**时，点击出现的"挂载节点模版"图标按钮（青色圆形，连接图标）；
- 在右侧"属性显示栏"选中根节点或核算子节点后，点击顶部"编辑"按钮左侧的"挂载节点模版"文字按钮。

**操作流程**：

1. 点击入口后弹出"**节点模版选择**"弹窗，顶部提示当前挂载目标节点名称；
2. 弹窗表格列出系统中所有**节点模版**（自动过滤，仅显示 templateType=1 的模版，含名称、描述、创建时间）；
3. 单击表格行选中要挂载的节点模版（单选，高亮当前行），底部"确定挂载"按钮随之启用；
4. 点击"确定挂载"，系统执行复制：
   - 将所选节点模版根节点的**全部子节点**（不含根节点本身）递归复制到目标父节点之下；
   - 同步复制每个节点对应的 `sys_emission_node_config`（碳排放因子、采集点关联等）与 `sys_emission_node_info`（节点编码、简称、边界说明等）；
   - 每个新节点通过 `source_node_id` 字段记录其来源节点ID，便于追溯挂载来源；
   - 顶层挂载节点排序自动追加在目标父节点现有子节点之后，子树内部保持来源排序；
5. 挂载成功后弹窗关闭，左侧树自动刷新展示新挂载的子结构。

**说明与限制**：

- 仅可在根节点或核算子节点下挂载，其他节点类型不显示入口；
- 仅可挂载节点模版（templateType=1），核算模版不可作为挂载来源；
- 挂载是**复制**操作，挂载后原节点模版不受影响；新节点与来源节点之间通过 `source_node_id` 软关联（无外键约束），删除一方不会影响另一方；
- 若节点模版根节点下无任何子节点，挂载操作不会产生任何节点；
- 若无可用节点模版，弹窗会提示"暂无可用节点模版，请先在模版列表中创建节点模版"。

## 八、常见问题与解答

### Q1：树状结构中无法添加新节点怎么办？

**检查清单**：

1. 确认当前节点是否允许添加子节点：
   - 站点节点可以添加集中器
   - 集中器节点可以添加电表
   - 电表节点可以添加子电表（建立级联关系）
2. 如果按钮不可用，可能是节点类型限制

### Q2：删除节点时提示"该节点处于启用状态"？

系统规则：只能删除已停用的节点。请先停用该节点，然后再执行删除操作。

### Q3：电表型号选择弹窗中搜索不到型号？

**可能的原因**：

1. 型号名称与搜索关键词不匹配
2. 使用拼音首字母搜索时，需输入型号名称的拼音首字母（如搜索"单相"可输入"DX"）
3. 如果确实没有该型号，请点击"新增"按钮创建

### Q4：更改电表级联关系时提示"该集中器下暂无其他电表"？

这表示当前电表所在的集中器下没有其他电表可作为其上级。此时只能选择"无上级电表"或先添加其他电表。

### Q5：删除字典分类时提示有启用的字典项？

系统规则：含有启用字典项的分类无法删除。请先将所有字典项停用（点击状态切换按钮），然后再尝试删除分类。

### Q6：集中器地址或电表地址输入不了字母？

这是系统的安全校验机制。集中器地址和电表地址仅支持数字（0-9），输入的字母会被自动过滤掉。

### Q7：拼音编码是如何生成的？

系统会根据节点名称自动生成拼音编码。例如输入"三汲站信号楼"，系统会自动生成对应的拼音首字母编码。该编码在创建后不可修改。

### Q8：挂载节点模版时弹窗列表为空？

"节点模版选择"弹窗仅显示**节点模版**（templateType=1）。若列表为空，说明系统中尚未创建节点模版，请先在模版列表页点击"新建节点模版"创建一个包含所需层级结构的节点模版，再回到核算模版执行挂载。注意：核算模版（templateType=2）不可作为挂载来源。

### Q9：挂载后的节点与原节点模版是什么关系？

挂载是**复制**操作：系统将节点模版根节点下的全部子节点递归复制到当前核算模版的指定核算点下，并同步复制节点配置与节点信息。每个新节点通过 `source_node_id` 字段记录来源节点ID（软关联，无外键约束）。挂载后原节点模版不受影响，删除或修改原节点模版不会影响已挂载的复制节点，反之亦然。

## 十一、碳排放因子模版管理

### 11.1 功能说明

碳排放因子模版管理用于管理多套碳排放因子设置库（模版）。每个模版可针对不同能耗小类设置缺省碳排放因子。核算模版通过关联因子模版，在采集点未单独设置碳排放因子时自动使用模版缺省因子。

### 11.2 页面入口

在"碳排放核算参数设置"页面左侧菜单中，点击"碳排放因子设置"→"碳排放因子模版管理"进入。

### 11.3 模版列表

页面以表格形式展示所有因子模版，列包括：模版名称、模版说明、共享状态（共享/私有）、启用状态（启用/停用）、创建时间。

每行操作栏提供三个按钮：

- **编辑因子**（绿色）：进入该模版的缺省因子配置界面
- **编辑信息**（橙色）：编辑模版名称、说明、共享/私有、启用/停用
- **删除**（红色）：删除模版（同时清理该模版下全部缺省因子配置）

### 11.4 新建模版

点击页面上方"新建模版"按钮，在弹窗中填写：

- **模版名称**（必填，唯一）
- **模版说明**（可选）
- **是否共享**（默认共享）

创建后模版出现在列表中，默认启用状态。

### 11.5 编辑因子（缺省因子设置）

点击模版行的"编辑因子"按钮，进入该模版的因子配置界面。

#### 11.5.1 添加能耗子类

1. 点击"添加能耗子类"按钮，弹出选择对话框
2. 先选择"能耗大类"（购入的电力 / 购入的热力 / 化石燃料 / 废弃物处理）
3. 再选择"能耗小类"（从数据字典中该大类下未配置的小类中选择）
4. 点击"下一步：选择因子"，系统自动打开对应的因子选择对话框
5. 在因子列表中选择一条因子，点击"确定"
6. 因子信息（ID、名称、值、单位、说明）作为快照保存到该模版的缺省因子配置中

#### 11.5.2 更换因子

在列表中点击"更换因子"，重新打开因子选择对话框，选择新因子后覆盖原有配置。

#### 11.5.3 删除缺省因子

点击行内"删除"按钮，确认后删除该小类的缺省因子配置。

### 11.6 模版拷贝

在模版列表中点击"拷贝"按钮（或从因子模版选择弹窗中操作），输入新模版名称后，系统在事务中复制模版记录及其全部缺省因子配置，生成新模版。

### 11.7 核算模版关联因子模版

在"碳排放核算模版管理"页面编辑核算模版（templateType=2）属性时：

1. 编辑弹窗中显示"碳排放因子模版"字段
2. 点击"选择碳排放因子模版"按钮，弹出因子模版选择弹窗
3. 弹窗列表显示所有共享模版和自己创建的模版
4. 选中一行后点击底部"选择"按钮，将该因子模版ID写入核算模版
5. 点击"确定"保存核算模版属性

#### 因子模版选择弹窗操作

- **选择**：选中一行后点击底部"选择"按钮
- **新建模版**：在弹窗中直接创建新因子模版
- **拷贝模版**：从选中行拷贝生成新模版
- **编辑因子**：跳转到"碳排放核算参数设置"页面并自动打开该因子模版的因子编辑界面（仅自有模版可用）
- **编辑信息**：编辑选中因子模版的名称/说明/共享状态（仅自有模版可用）

**编辑锁定规则**：自己创建的因子模版正在被其他用户创建的核算模版引用时，"编辑因子"和"编辑信息"按钮锁定不可用，防止修改影响引用方的核算结果。

### 11.8 采集点碳排放因子为空时的回退机制

在"碳排放模型设计"中添加采集点时，碳排放因子输入项允许为空。

**核算时因子优先级**：

1. 优先使用采集节点 `sys_emission_node_config` 中配置的碳排放因子
2. 若为空，自动回退到核算模版关联的因子模版中该小类的缺省因子（`sys_emission_default_factor` 表，按 `template_id` + `subcategory_name` 匹配）
3. 均为空时跳过碳排放计算

### 11.9 共享与私有

- **共享**（默认）：所有用户可见可使用，但只有创建人可编辑
- **私有**：仅创建人可见可使用
- 在编辑信息弹窗中通过"是否共享"开关切换

### 11.10 启用与停用

- 在编辑信息弹窗中通过"是否启用"开关切换
- 停用的模版不参与核算
