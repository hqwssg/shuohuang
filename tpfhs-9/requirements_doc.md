## 1. 项目概述

### 1.1 项目背景

本系统是一个基于浏览器访问的碳排放模型设计系统，用于帮助用户创建和管理碳排放核算模版，实现碳排放的自动化核算。系统支持树形结构的节点管理，提供灵活的属性配置和计划任务调度功能。

### 1.2 技术架构

| 层级    | 技术栈                   | 版本    |
|:----- |:--------------------- |:----- |
| 前端框架  | Vue.js                | 3.x   |
| 前端组件库 | Element Plus          | 2.x   |
| 构建工具  | Vite                  | 6.x   |
| 后端框架  | Spring Boot           | 3.2.0 |
| 数据库   | MySQL                 | 8.0+  |
| ORM框架 | Spring Data JPA       | 3.2.x |
| 定时任务  | Spring Scheduled      | -     |
| 异步任务  | Spring Async + 自定义线程池 | -     |

#### 4.1.22 能耗分类数据字典表 (sys_emission_energy_category)

用于支撑电表/采集点的"能耗场景大类 → 能耗二级分类 → 能耗三级分类"三级级联选择。该表为自关联三级树结构（parent_id 指向本表 id，顶级为 NULL），通过 level 字段标识层级（1/2/3）。

| 字段名           | 类型           | 约束                                                                    | 描述                              |
|:------------- |:------------ |:--------------------------------------------------------------------- |:------------------------------- |
| id            | BIGINT       | PRIMARY KEY, AUTO_INCREMENT                                           | 主键ID                            |
| category_code | VARCHAR(50)  | NOT NULL, UNIQUE                                                      | 分类编码（如 EC01、EC0101、EC010101），唯一 |
| category_name | VARCHAR(100) | NOT NULL                                                              | 分类名称（如"生产用能"、"牵引供电"）            |
| parent_id     | BIGINT       | FOREIGN KEY REFERENCES sys_emission_energy_category(id) ON DELETE CASCADE | 父级分类ID，顶级为 NULL；删除父级时级联删除子级     |
| level         | TINYINT      | NOT NULL                                                              | 分类层级：1-一级，2-二级，3-三级             |
| remark        | VARCHAR(500) | -                                                                     | 备注说明                            |
| sort_order    | INT          | DEFAULT 0                                                             | 排序顺序，数值越小越靠前                    |
| status        | TINYINT      | DEFAULT 1                                                             | 状态：1-启用，0-停用                    |
| created_by    | BIGINT       | -                                                                     | 创建人ID                           |
| updated_by    | BIGINT       | -                                                                     | 更新人ID                           |
| created_at    | TIMESTAMP    | DEFAULT CURRENT_TIMESTAMP                                             | 创建时间                            |
| updated_at    | TIMESTAMP    | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP                 | 更新时间                            |

**预置分类数据：**

- **一级分类（4 项）：** EC01 生产用能、EC02 生产辅助用能、EC03 非生产综合用能、EC04 混合场景用能
- **二级分类（13 项）：** 生产用能下 3 项（EC0101 牵引供电、EC0102 内燃机车牵引、EC0103 电力机车牵引能耗）；生产辅助用能下 6 项（EC0201 线路与桥隧维护、EC0202 机车运用与检修、EC0203 运输组织、EC0204 通信与信号、EC0205 车辆系统、EC0206 供电系统）；非生产综合用能下 4 项（EC0301 办公区、EC0302 生活区、EC0303 生产辅助附属、EC0304 其他）
- **三级分类（21 项）：** 在二级分类下进一步细化，如 EC010101 接触网损耗、EC020101 线路维护、EC030301 福利区 等
- **分类原则：** 宜细不宜粗，条件允许时细化至三级；监测点未覆盖细分项目时按第一级统计

| `Disable_all_meter`         | 0   | 是否允许一键禁用集中器下所有电表。0：不允许；1：允许    |

### 5.11 能耗分类数据字典接口

能耗分类数据字典接口提供三级能耗分类的查询能力，供前端表单级联下拉框使用。Controller 文件为 `EnergyCategoryController.java`，前缀 `/api/energy-categories`。

| API路径                                        | HTTP方法 | 功能描述                                   |
|:-------------------------------------------- |:------ |:-------------------------------------- |
| `/api/energy-categories`                     | GET    | 获取所有能耗分类（扁平列表，按 level 与 sort_order 排序） |
| `/api/energy-categories/level/{level}`       | GET    | 获取指定层级（1/2/3）的能耗分类                     |
| `/api/energy-categories/children/{parentId}` | GET    | 获取指定父级下的子分类                            |

## 7. 计划任务配置JSON结构

```json
{
  "cycleType": "DAILY",
  "startDate": "2026-01-01",
  "endDate": "",
  "executionTime": "02:00",
  "interval": 1,
  "weekDays": [],
  "monthDays": "",
  "yearMonths": "",
  "yearDays": []
}
```

| 字段            | 类型           | 说明                                         |
|:------------- |:------------ |:------------------------------------------ |
| cycleType     | String       | 执行周期：DAILY/WEEKLY/MONTHLY/QUARTERLY/YEARLY |
| startDate     | String       | 起始日期(yyyy-MM-dd)                           |
| endDate       | String       | 截止日期(yyyy-MM-dd)，空表示无限制                    |
| executionTime | String       | 执行时间(HH:mm)                                |
| interval      | Integer      | 重复间隔，默认1                                   |
| weekDays      | Array        | 周执行的星期列表(1-7)                              |
| monthDays     | Array/String | 月执行的日期列表                                   |
| yearMonths    | Array/String | 年执行的月份列表                                   |
| yearDays      | Array/String | 年执行的日期列表                                   |
